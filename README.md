## Kurulum

pip install doku2d


## Kullanım

python -m doku2d create proje_adı

Proje dizini içinde

python -m doku2d run 

ile oyunu çalıştırabilirsiniz.

## Derleme

python -m doku2d build

ile kullandığınız işletim sistemine göre oyunu derleyebilirsiniz. Ayrıca androide export etmek istiyorsanız android sdk ve ndk yı kurduktan sonra

python -m doku2d build android 

komutu ile apk ve aab dosyası elde edebilirsiniz. Daha detaylı bilgileri belgelerden ulaşabilrsiniz.
