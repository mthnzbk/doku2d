# 6. Menü, tema ve yerelleştirme

**Hedef:** Oyun kapanmadan dil değiştiren bir arayüz yapmak.

1. `menu.py` dosyasında iki küçük katalog oluştur. Bunları sonradan JSON
   dosyalarına taşıyabilirsin:

   ```python
   from doku2d import Button, Game, HBox, Label, tr

   game = Game(size=(640, 240))
   game.localization.add_catalog('en', {'status': 'Ready', 'language': 'Change language'})
   game.localization.add_catalog('tr', {'status': 'Hazır', 'language': 'Dili değiştir'})
   game.ui.theme = game.ui.theme.variant(radius=10, font_size=18)
   row = game.add(HBox())
   row.position, row.size = (30, 40), (570, 44)
   button = row.add(Button(text=tr('language'), fit_text=True))
   row.add(Label(text=tr('status'), fit_text=True))

   def change_language():
       game.locale = 'tr' if game.locale == 'en' else 'en'

   button.pressed.connect(change_language)
   game.run()
   ```

2. Düğmeye birkaç kez bas. `tr` ile işaretlenen metinler yeniden çözülür.
3. Dosyaya geçmek istediğinde `game.localization.load_catalog('tr',
   'res://locale/tr.json')` kullan. JSON içeriği `{ "status": "Hazır" }` biçimindedir.

**Kontrol:** Düğme metne göre genişler, yanındaki etiket yer değiştirir.
